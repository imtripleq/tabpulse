# Code of conduct

TabPulse adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The full text at that link, including its scope and enforcement guidelines, applies to this project as written.

In short: be kind, assume good intent, and keep discussion about the work. Harassment of any kind isn't tolerated. This covers the repository's issues, pull requests and discussions, and anywhere you speak for the project.

## Reporting

To report a problem, email denniskcc@hotmail.com. The maintainer reads every report, keeps it confidential, and decides what to do using the Covenant's enforcement guidelines.
