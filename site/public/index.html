macOS 14+, Claude Code 2.1.78+, Ghostty 1.4+ for tab spinners. The menu bar works with any terminal. Free, MIT licensed, no network calls.

Claude Code only animates the tab you’re looking at, so from any other tab a busy session looks idle.

TabPulse puts a spinner on every working tab, a ● on any tab that needs you, and a session count in the menu bar. Here is one night with it.

  1. 23:10You start four sessions and step away.

    Every working tab gets a spinner, and they all step together, one frame every 0.12 seconds. The ✳︎ in the menu bar counts the sessions that are working.

    Click it for the list: what each session is doing, for how long, and a click on a row jumps to its tab.

    Try it on this page. Switch to another browser tab for a few seconds and watch this one’s title spin. Your browser slows hidden tabs to about one frame a second; the app doesn’t. Stay away for 20 seconds and it switches to ●.

  2. 23:42One needs you.

    Claude stopped to ask for permission to use Edit. Its tab shows ●, the menu bar gets an orange dot, and the session moves to the top of the list.

    Press ⌃⌥⌘J from any app to jump to it. It needs no Accessibility permission. TabPulse doesn’t add a banner for this, though with sounds on you hear Ping.

  3. 23:47Five minutes later, one reminder.

    If a session has waited on you for five minutes, you get one banner: Still needs you. It comes once per wait, skips the tab you’re looking at, and clicking it takes you to the tab.

  4. 00:30You close the lid.

    While Claude works, TabPulse keeps your Mac out of idle sleep. The screen can still sleep. That part is on by default.

    Keeping it awake with the lid closed is optional and off by default. It asks for your admin password once, to add a rule that allows pmset disablesleep and nothing else. Lid sleep comes back on when the work ends, when the battery drops to 20% on battery power, or when the Mac gets hot.

    Macs managed by an employer often block the admin step. As the app’s own dialog puts it: don’t put a working Mac in a bag.

  5. 03:15Background agents keep it spinning.

    Claude’s reply has ended, but a workflow is still reviewing in the background, so the session stays working. Agents, teammates and cloud sessions count too. This needs a Claude Code version that passes background_tasks to its Stop hook; on older versions the session counts as done when the reply ends.

    Background shell commands and monitors don’t, since those are often servers that never end. If background work sends nothing for 30 minutes, the session counts as done, so a stuck task can’t keep your Mac up all night.

  6. 06:50Everything finished.

    Everything finished overnight, so the Finished banners are waiting when you open the lid. Each one waits about ten seconds in case a hook sends Claude back to work. Then it arrives, for example “Finished: migrate db”. Banners skip the tab you’re looking at, and skip any turn you stopped yourself.

    The tabs get Claude’s own titles back. With nothing waiting, ⌃⌥⌘J goes to the newest finished session you haven’t seen.

  7. 07:02Morning.

    You’ve seen everything, so the green dot is gone, the ✳︎ is grey and your Mac can sleep again.

Install it before tonight

One line in a terminal. It installs TabPulse to ~/Applications, adds the hooks and starts at login.

curl -fsSL https://raw.githubusercontent.com/imtripleq/tabpulse/main/install.sh | bash
  1. When macOS asks whether TabPulse may control Ghostty, click OK.
  2. Start claude and look for ✳︎ in your menu bar.
  3. Restart any sessions that were already open, so they pick up the hooks.

You need macOS 14 or newer, Claude Code 2.1.78 or newer, and Ghostty 1.4 or newer for the tab spinners. The menu bar works with any terminal. On macOS 14, also run brew install jq.

Read install.shReleases

Two things from the night are off until you turn them on in Options: Keep awake with lid closed, and Play sounds (Ping when one needs you, Glass when one finishes). TabPulse follows Reduce Motion, and the app makes no network calls.

As a Claude Code plugin

Use this if you don’t want the installer to touch settings.json. Inside Claude Code:

/plugin marketplace add imtripleq/tabpulse /plugin install tabpulse@tabpulse

Then install the app on its own:

curl -fsSL https://raw.githubusercontent.com/imtripleq/tabpulse/main/install.sh | bash -s -- --app-only

Uninstall

Removes the hooks first, after a backup, then the app, the login item and the lid-closed rule if you added it.

curl -fsSL https://raw.githubusercontent.com/imtripleq/tabpulse/main/uninstall.sh | bash

Plugin users also run /plugin uninstall tabpulse@tabpulse.

How it works

A small hook script writes each session’s state to a JSON file. It prints nothing and always exits 0, so it can’t block or change a session. TabPulse reads those files once a second, updates the menu bar and sets the Ghostty tab titles.

  1. Claude Codenine hook events
  2. tabpulse-hook.shbash and jq
  3. sessions/<id>.jsonin ~/.claude/tabpulse
  4. TabPulse.appreads once a second
  5. Tabs and menu bartitles over AppleScript

  • Nothing leaves your Mac

    The app makes no network requests. The installer downloads the release from GitHub, and that’s all.

  • One section of settings.json

    The installer checks that settings.json is valid JSON, saves settings.json.tabpulse-backup, then edits its hooks section and nothing else.

  • Read it before you run it

    The installer is one short shell script. It checks the download against its SHA-256 file to catch a broken download. Read install.sh

Questions

How do I get notified when Claude Code finishes?

About ten seconds after a session finishes, TabPulse sends a Finished banner, and clicking it jumps to the tab. Banners skip the tab you’re looking at and any turn you stopped yourself. If a session has waited on you for five minutes, you also get one Still needs you reminder.

Does it work with iTerm2, Terminal, Warp or tmux?

The menu bar count, session list, notifications, reminders and keep awake work with any terminal. Tab spinners and click to jump need Ghostty 1.4 or newer, with Claude running directly in a Ghostty tab, not inside tmux, screen or zellij. Spinners for other terminals are help wanted.

Can it play a sound when Claude is done or needs me?

Yes, once you turn on Play sounds in Options; it’s off by default. You hear the built-in macOS sounds: Ping when a session starts waiting on you or a reminder goes out, and Glass when one finishes. Neither plays for the tab you’re looking at.

How do I keep my Mac awake while Claude Code works?

You don’t have to do anything: Keep Mac awake while Claude works is on by default. It holds off idle sleep while a session works and lets go about 15 seconds after; the screen can still sleep. Lid-closed mode stays off until you turn it on, asks for your admin password once, and turns lid sleep back on when the work ends, at 20% battery on battery power, or when the Mac gets hot.

What does it change in settings.json?

Just the hooks section, after saving settings.json.tabpulse-backup. The plugin route doesn’t edit settings.json at all, and the uninstaller removes the hooks again.

Does it phone home?

No. The app makes no network calls. The installer downloads the release zip from GitHub and checks it against its SHA-256 file.

Why does macOS say it can’t open TabPulse?

TabPulse is ad-hoc signed and isn’t notarized yet. The installer removes the quarantine flag so it opens; if you unzipped TabPulse.zip by hand, run xattr -dr com.apple.quarantine ~/Applications/TabPulse.app. Because macOS treats each version as a new app, it asks again for permission to control Ghostty after an update.

Is it free? How do I uninstall it?

Yes, TabPulse is free and open source under the MIT license. To remove it, run the uninstall command: it takes the hooks out of settings.json first, after a backup, then removes the app, the login item and the lid-closed rule if you added it. Plugin users also run /plugin uninstall tabpulse@tabpulse.

Ghostty can already mark a tab with a bell. Why this?

When a program rings the bell, Ghostty can put 🔔 on that tab’s title. TabPulse animates every working tab, clears the marker on its own, and adds the menu bar count, the session list, ⌃⌥⌘J, notifications and keep awake.

Will Claude Code or Ghostty make this obsolete?

Maybe one day. Ghostty has started on a way for programs to report their status, and its app ignores it for now. The menu bar, the jump shortcut, reminders and keep awake don’t depend on the tabs either way.
